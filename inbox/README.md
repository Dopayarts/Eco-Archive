# Photo inbox

Drop photos of a plant here, one folder per plant, and the daily routine archives it first.

    inbox/<plant name>/leaf.jpg     one leaf flat on plain white paper, tip pointing up, stalk down
    inbox/<plant name>/plant.jpg    the whole plant, in good light
    inbox/<plant name>/flower.jpg   (optional) a close-up of a flower

On GitHub: open the eco-archive repo, go into `inbox`, click **Add file > Upload files**,
and type the folder name before the file names (for example `ugwu/leaf.jpg`).
PNG, JPG or WEBP all work. A `notes.txt` with the name, where you found it and your
research is welcome; the routine reads it.
